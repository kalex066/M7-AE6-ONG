Desarrollo de una aplicacion de una ONG para gestionar voluntarios y eventos. El objetivo del proyecto es practicar la realizacion de operaciones CRUD (Create, Read, Update and Delete). Se creo una app donde se establecioern vistas basadas en funciones para realizar el CRUD con voluntarios, y vistas basadas en clases para realizar el CRUD a los eventos; de forma tal que pude practicar ambas metodologias.
Se creron los diferentes templates, el proyecto se conecto a mysql workbench para tener persistencia de datos y se crearon varios registros de voluntarios y eventos para poder realizar las operaciones.
